# Evolución de las herramientas de Inteligencia Artificial 2022-2026

## Descripción del proyecto

Este proyecto analiza la evolución de diferentes herramientas de Inteligencia Artificial durante el período 2022-2026.

El objetivo es observar cómo fueron evolucionando sus características, funciones y posibilidades de uso, y presentar los resultados mediante un sitio web interactivo.

El análisis se realizó utilizando información organizada en dos archivos Excel y un archivo Word.

---

## Objetivo

Analizar la evolución de las principales herramientas de Inteligencia Artificial entre 2022 y 2026, identificando sus principales características, funciones y cambios durante el período estudiado.

### Objetivos específicos

- Identificar las principales herramientas de Inteligencia Artificial analizadas.
- Observar su evolución durante el período 2022-2026.
- Comparar las funciones disponibles en cada herramienta.
- Identificar las principales tendencias relacionadas con la evolución de la IA.
- Representar los resultados mediante gráficos y elementos visuales.
- Presentar los resultados en un sitio web.

## Análisis

Los datos de los archivos Excel fueron utilizados para identificar tendencias y realizar comparaciones entre las diferentes herramientas de Inteligencia Artificial.

El archivo Word permitió complementar el análisis con información histórica y explicativa sobre la evolución de estas tecnologías.

Los resultados fueron posteriormente utilizados para desarrollar el sitio web del proyecto.

## Herramientas utilizadas

### Perplexity

Utilizada para la búsqueda y recopilación de información y fuentes relacionadas con la evolución de las herramientas de Inteligencia Artificial.

### Cuaderno Gemini

Utilizado para analizar los archivos Excel y Word, identificar tendencias, comparar información y organizar los principales resultados del proyecto.

### Claude

Utilizado para generar el código HTML del sitio web a partir de la información analizada.

### GitHub

Utilizado para almacenar y documentar el código del proyecto.

### Netlify

Utilizado para publicar el sitio web y permitir su acceso mediante Internet.
